# homebrew-tap

Homebrew casks for Graham Otte's apps, one per file in [`Casks/`](Casks).

| App | Install |
| --- | --- |
| [Badge On Bar](https://github.com/grahamotte/BadgeOnBar) — Mirror Dock badge counts in the menu bar | `brew install grahamotte/tap/badge-on-bar` |
| [Cubby](https://github.com/grahamotte/Cubby) — Fast, simple file manager with list, icon, column, and gallery views | `brew install grahamotte/tap/cubby` |
| [Freya Player](https://github.com/grahamotte/FreyaPlayer) — Video player for personal Plex and Jellyfin libraries | `brew install grahamotte/tap/freya-player` |
| [Scamp Micro Deck](https://github.com/grahamotte/ScampMicroDeck) — Music player with the tedious charm of a real vinyl record player | `brew install grahamotte/tap/scamp-micro-deck` |
| [Sundial](https://github.com/grahamotte/Sundial) — Schedule local commands and see whether each run passed or failed | `brew install grahamotte/tap/sundial` |

Update with `brew upgrade`. Each app's release workflow updates its cask after the release is published.
